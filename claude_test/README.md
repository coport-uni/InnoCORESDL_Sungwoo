# claude_test/

Scratch area for debug scripts, one-off experiments, and diagnostic code
(CommonClaude §3 Debug File Management). Production-quality tests go in
`tests/`. When adding a file here, add a row below.

| File | Purpose | Learned |
|---|---|---|
| `conftest.py` | Fixtures + `FakeL1`, an httpx `MockTransport` stand-in for all three cell shapes (cell1–3, cell4, Cell 5). Its hotplate warms 5 °C per state read while heating, so `until:` polls converge in a handful of reads. Deliberately test-level, never a deployable mock server (spec §9). | The L1 OpenAPI is shape-agnostic (one router for every shape), so the fake serves the union too — a *narrower* fake would let tests catch wrong-shape actions the real dry run cannot, which is worse than useless. Wrong-shape calls answer 409, like the cells' defensive stubs. The pump answers are stateful (valve `?6` digit, contained volume) with a shape-aware `/v1/diagnose`, so pump scenarios assert real readbacks rather than canned zeros. `FakeL1.pan_g` models what the balance is carrying: a test for a scenario with an operator step sets it *while the run is paused*, which is what the operator physically does at that pause — leaving it empty makes `verify_vial_present` fail, correctly. `HOME_MM` is **not 0** on purpose: on the real bench the 0 mm encoder origin sits on the mechanical stop, and homing there drove the carriage into it until the amp tripped Err16.0 and killed the servo. A fake that homed to 0 would let a scenario asserting `y_mm <= tolerance` pass here and damage hardware on the bench, so the fake parks where the cell parks. |
| `test_orchestrator.py` | Orchestrator acceptance tests: the six validator errors, the demo scenarios end-to-end (linear, weigh, Cell 5 warmup, and the three Cell 5 bench demos — lamp blink, hotplate 30 °C, Z cycles), the cell1 pump-cycle demo (validates, completes with the 1 unrolled + 9 batched = 10 cycles asserted, aborts before `pump/cycle` on an injected aspirate fault), runlog files, the three `on_fail` policies, abort's stop broadcast, `resume --from-step`, the hazard gate (heater/lamp gated, GETs not), the `wait_s` step (holds, params, bad-value rejection, not gated, cut short by abort), the `until:` polled GET (converges, times out, rejects POST), the scenario-declared operator `pause:` (holds without step mode, fires exactly once, reported separately from the motion gate, rejected on a `parallel` child), the wrong-shape 409, a drift guard against the real L1 OpenAPI, the `/v1` HTTP surface, and the dry run's numeric bounds checking. | `resume(from_step=…)` must re-read the step after the pause gate, or the loop runs the stale one; `resume()` has to flip the state itself so a poller never sees a stale `paused`; and the drift guard has to compare request *fields*, not just paths — that is what would have caught the `on`/`enabled` mismatch. The bounds tests must assert that a **valid** body passes, not only that a bad one fails: the first `_check_bounds` used `value.__lt__(limit)`, which returns the truthy `NotImplemented` for int-vs-float, so it flagged every correct integer field. |

| `smoke_l1.py` | Operator-supervised M0 smoke test (spec §4.2): drives one cell server's `/v1` endpoints, stops before every hazardous check until the operator types `go`, and prints a Markdown table for `docs/L1_AUDIT.md`. | `preflight.py` | Bench pre-flight, read-only: enumerates the attached USB/FTDI devices, resolves every address in `server/nuc*/*.toml` against them, resolves *unset* `port` fields against each driver's own auto-detect signature (`AUTO_DETECT`), checks that this user may actually open every port that resolved, flags leftover `TBD-…` placeholders, and checks whether a cell's TCP port is already taken.
