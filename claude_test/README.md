# claude_test/

Scratch area for debug scripts, one-off experiments, and diagnostic code
(CommonClaude §3 Debug File Management). Production-quality tests go in
`tests/`. When adding a file here, add a row below.

| File | Purpose | Learned |
|---|---|---|
| `conftest.py` | Fixtures + `FakeL1`, an httpx `MockTransport` stand-in for all three cell shapes (cell1–3, cell4, Cell D). Deliberately test-level, never a deployable mock server (spec §9). | The L1 OpenAPI is shape-agnostic (one router for every shape), so the fake serves the union too — a *narrower* fake would let tests catch wrong-shape actions the real dry run cannot, which is worse than useless. Wrong-shape calls answer 409, like the cells' defensive stubs. |
| `test_orchestrator.py` | Orchestrator acceptance tests: the six validator errors, both demo scenarios end-to-end, runlog files, the three `on_fail` policies, abort's stop broadcast, `resume --from-step`, the hazard gate (heater/lamp gated, GETs not), the wrong-shape 409, a drift guard against the real L1 OpenAPI, and the `/v1` HTTP surface. | `resume(from_step=…)` must re-read the step after the pause gate, or the loop runs the stale one; `resume()` has to flip the state itself so a poller never sees a stale `paused`; and the drift guard has to compare request *fields*, not just paths — that is what would have caught the `on`/`enabled` mismatch. |
| `smoke_l1.py` | Operator-supervised M0 smoke test (spec §4.2): drives one cell server's `/v1` endpoints, stops before every hazardous check until the operator types `go`, and prints a Markdown table for `docs/L1_AUDIT.md`. Suites: discovery, balance, linear, pump, gantry, zstage, hotplate, lamp. | Verdicts for the pump must come from the eye, not the `?6` reply (LearnedPatterns #1); the gantry check has to ask whether *both* Z axes moved; heater and lamp checks are gated exactly like motion. |
| `preflight.py` | Bench pre-flight, read-only: enumerates the attached USB/FTDI devices, resolves every address in `server/nuc*/*.toml` against them, flags leftover `TBD-…` placeholders, and checks whether a cell's TCP port is already taken. Never opens a serial handle, so it is safe to run while a cell server is up. | Half of a bench day is lost to "which adapter is which"; answering it before `python -m server` is cheap. Built-in `ttyS*` ports have to be filtered out or they drown the real devices. |
| `smoke_l1.py` (probes) | `--suite stop` (A4) and `--suite concurrency` (A7) drive a long move in a worker thread and measure a second request against it. | The stop probe found GAP-9 before it ever reached the bench: `/v1/stop` waits on the same lock as the move, so it reports `preempted=False`. A safety probe that only asks the operator "did it stop?" would have missed the *why*. |
| `pytest.ini` | `asyncio_mode = auto` so the async tests run without per-test markers. | |
